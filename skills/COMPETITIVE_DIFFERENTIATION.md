# COMPETITIVE DIFFERENTIATION

## Objective

Maximize portfolio value without attempting to predict or guarantee sales. Adobe explicitly encourages distinct, high-quality, commercially relevant generative AI submissions and warns against near-duplicate content.

## Before generation

Generate at least 3 materially different concepts around a demand signal. Reject concepts that differ only by:

- crop;
- aspect ratio;
- color;
- filter;
- rotation/flipping;
- tiny pose/background changes.

Each selected concept must have a different commercial message, use case, setting, subject relationship, or composition.

## Differentiation dimensions

Look for a combination of:

- under-served buyer use case;
- specific contemporary context;
- unusual but commercially useful composition;
- strong negative space;
- authentic environmental detail;
- visual metaphor that remains clear;
- culturally informed but non-proprietary setting;
- premium photographic execution;
- technically difficult detail handled correctly.

## Competitive gap analysis

For each candidate ask:

`What is already generic about this idea?`
`What do most AI outputs get wrong?`
`What buyer need is missing?`
`What can this concept communicate that a generic stock image cannot?`
`Can the improvement be visible in one thumbnail?`

If the differentiation cannot be described concretely, do not treat the asset as differentiated.

## Portfolio strategy

Maintain a portfolio map by theme, buyer use case, subject, setting, composition and date. Prefer filling meaningful gaps instead of producing more versions of an already-covered concept.

## Important constraint

Never imitate another contributor's portfolio, composition or protected creative identity. Originality means solving a buyer problem with an independently directed image.
