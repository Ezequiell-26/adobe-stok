# Image Generation Prompt Template

Use this after the master system passes the concept.

```text
Create a commercially useful, original stock photograph for licensing.

SUBJECT:
[subject]

SCENE:
[scene]

COMPOSITION:
[composition]

CAMERA / PHOTOGRAPHY:
[photographic direction]

LIGHTING:
[lighting]

MATERIALS / PHYSICS:
[materials]

COLOR:
[color direction]

NEGATIVE SPACE:
[where copy space should be]

REALISM:
Photorealistic commercial photography, physically plausible geometry,
natural textures, coherent depth, coherent lighting, accurate reflections.

SAFETY:
No logos, trademarks, brand names, recognizable branded packaging,
celebrity likenesses, fictional copyrighted characters, protected artwork,
watermarks, signatures, timestamps, random text, or copied campaign/product
designs.

QUALITY:
Accurate perspective, realistic shadows, realistic materials, clean edges,
no duplicated objects, no fused objects, no malformed anatomy, no generative
artifacts, no corrupted typography.

The composition must be useful for advertising, websites, presentations,
editorial-layout-like commercial design, or marketing where appropriate.
```
